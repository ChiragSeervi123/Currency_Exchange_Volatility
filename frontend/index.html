About · FXLab

About the Project

FXLab is a Probability and Statistics project that studies how the U.S. dollar – Indian rupee exchange rate moves, how volatile it is, and how probability models can describe its future.

How it works

  1. You choose an analysis and its inputs in this web page (HTML, CSS, JavaScript).
  2. The page sends a JSON request to the R backend, an R Plumber API running on your computer.
  3. R validates the request and performs every statistical calculation.
  4. R returns structured JSON; the page draws tables and charts from it (Chart.js). The browser never computes statistics.

The status button (top right) shows whether the R backend is reachable. The API can also be explored at /__docs__/ while the backend is running.

Data

USD/INR: FRED series DEXINUS (Indian rupees per U.S. dollar, noon buying rates in New York; Board of Governors of the Federal Reserve System, H.10 release). Broad dollar strength: FRED series DTWEXBGS (Nominal Broad U.S. Dollar Index). The files are stored locally in data/; the app does not fetch live rates, so the latest value is always labelled with its date and is not a live quote. Days without a published rate (holidays) are excluded and counted, never filled in.

Methods and formulas

  • Log return: rt = 100 · ln(St / St−1) %; simple return: Rt = 100 · (St / St−1 − 1) %.
  • Sample variance s² = Σ(x − x̄)² / (n − 1); skewness m3/m23/2; kurtosis m4/m2² (normal = 3).
  • Volatility = SD of daily log returns; annualised volatility = daily SD × √252.
  • GBM: St+Δt = St · exp[(μ − σ²/2)Δt + σ√Δt · Z], Δt = 1 trading day, so E[ST] = S0eμT.
  • Monte Carlo standard error of the mean = SD / √N; probability intervals use the Wilson score method.
  • Tests: Student and Welch t-tests, chi-square and F intervals/tests, Brown-Forsythe, Jarque-Bera, Shapiro-Wilk, Ljung-Box, Newey-West robust mean test.
  • Regression: OLS with classical and HC1 (heteroskedasticity-robust) standard errors, Durbin-Watson and Breusch-Pagan diagnostics.

Assumptions and limitations

  • GBM assumes constant drift and volatility and independent shocks. Real USD/INR returns have heavier tails and volatility clustering, and the Reserve Bank of India intervenes in the market. Simulations are illustrations, not forecasts.
  • Annualising with √252 assumes roughly uncorrelated daily returns and 252 trading days per year.
  • With thousands of observations, tests detect even tiny effects: always judge practical size as well as p-values.
  • A regression of the exchange-rate level on time is descriptive only: levels are non-stationary, so its standard errors are not reliable.
